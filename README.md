# Manor Lords Farming Calculator 🌾

I built this calculator because I was tired of watching my crops rot in winter and having to use messy Excel spreadsheets to figure out the game's math. 

The farming mechanics in Manor Lords don't explicitly tell you the ratio of workers to field size. This tool solves that. You input the field size (in morgens) and soil fertility, and it instantly calculates your expected yield and warns you if you don't have enough families assigned to harvest on time (based on the community-tested 1 family per 0.6 morgens rule).

**Tech Stack:**
* Built with plain HTML, vanilla JavaScript, and Tailwind CSS.
* Single-file architecture for fast loading.
* 100% Mobile-first UI (designed to be used on your phone while playing on PC).
* Hosted on Vercel.

No ads, no paywalls. If this tool saved your settlement from starvation, you can buy me a beer to help fund the official .com domain!

# Calculadora Agrícola para Manor Lords 🌾

Hice esta calculadora porque estaba harto de perder las cosechas cada invierno y tener que usar hojas de cálculo para entender las matemáticas del juego.

Las mecánicas agrícolas de Manor Lords no te explican de forma clara el ratio de trabajadores por tamaño de campo. Esta herramienta soluciona eso. Introduces el tamaño en morgens y la fertilidad, y te calcula el rendimiento esperado. Además, te avisa si te faltan familias para cosechar a tiempo (basado en la regla de la comunidad: 1 familia por cada 0.6 morgens).

**Detalles técnicos:**
* Desarrollada con HTML, JavaScript nativo y Tailwind CSS.
* Arquitectura de un solo archivo para que cargue al instante.
* Interfaz 100% pensada para móviles (para usarla en el móvil mientras juegas en el PC).
